# Guias Documentais

Consulte o guia do artefato que precisar criar, interpretar ou atualizar. Os modelos estão em blocos Markdown dentro de cada guia. Substitua os marcadores e inclua somente links para documentos existentes.

| Artefato | Guia |
| --- | --- |
| Casos de uso, cenários e catálogo | [Casos de Uso](./use-case.md) |
| Regras locais, compartilhadas e vocabulário | [Regras de Negócio](./business-rule.md) |
| Percurso técnico, restrições, diagramas e testes | [Implementação](./implementation.md) |
| Decisões técnicas e substituição de decisões | [ADRs](./adr.md) |
| Organização do sistema e requisitos de qualidade | [Arquitetura](./architecture.md) |
| Runbooks e referências de contratos | [Operações e Contratos](./operations.md) |

O [mapa documental](../README.md) registra stack, comandos e áreas existentes. As [instruções da raiz](../../AGENTS.md) definem as fontes e convenções globais. Preencha os modelos apenas com comportamentos implementados, sem campos de ciclo de vida documental. Propostas e funcionalidades futuras pertencem a specs, fora de `docs/`.
